# 東急エレベーターGO！ (Tokyu Elevator Guide)
### 〜 東横線・大井町線 エレベーターナビ ＆ 夏休みの自由研究・現地調査ノート 〜

---

## 🌟 アプリ概要
「ベビーカーを押す人や車椅子の人、大きなスーツケースを持った人が、駅のどこから入れば階段なしで電車に乗れるか？」を解決するGPS連動ナビゲーションアプリ（Webプロトタイプ）です。

同時に、**小学生・中学生の「夏休みの自由研究・探究学習」**にそのまま使える**現地調査ノート＆レポート生成機能**を搭載しています。

---

## 🚀 主な機能

### 1. 🧭 GPS現在地ナビゲーション
- スマホのGPS（Geolocation API）を利用し、今いる場所から最も近い「地上エレベーター出入口」を自動特定。
- **距離・徒歩分数**（ベビーカー歩行を想定した分速約75mで計算）を表示。
- **改札・ホームへのスムーズな乗り換え手順**（地上 ➡️ 改札階 ➡️ ホーム階）をステップ形式でガイド。
- **Googleマップ連動**：ボタン1つで現在地からそのエレベーターまでの徒歩ナビを起動。
- **おうちシミュレーター**：現地に行かなくても「自由が丘駅前」「中目黒駅前」「武蔵小杉駅前」などにワープしてお試しテストが可能。

### 2. 🚉 東急線主要駅・構内図データ（東横線 TY / 大井町線 OM）
- **自由が丘駅**（TY07/OM10）：大井町線(1F)と東横線(2F)の立体交差。正面口スロープと北口（階段のみ）の違い。
- **中目黒駅**（TY03）：高架駅。日比谷線との同一ホーム対面乗り換え。
- **大岡山駅**（OM08）：地下駅。駅の上に「東急病院」が直結する特殊バリアフリー構造。
- **武蔵小杉駅**（TY11）：高架・JR立体連絡。東急スクエア4F直結の大型エレベーター。
- **二子玉川駅**（OM15）：高架駅。二子玉川ライズ連絡デッキ直通エレベーター。
- **渋谷駅**（TY01）：地下5階の超深層ホーム。ヒカリエ改札からホームへの高速直通エレベーター。
- **大井町駅**（OM01）：高架終着駅。ペデストリアンデッキ直結。

### 3. 📝 夏休みの自由研究ノート（現地調査チェックシート）
- **駅・エレベーターを選んで現地チェック**：
  - 「車椅子・子供用ボタンの高さ」「鏡の有無（バックで出るため）」「ドアの幅」
  - 「地上からエレベーターまでのスロープや段差」「点字・音声アナウンス」
  - 「気づいたことメモ」をその場で記録。
- **データの保存・出力**：
  - `localStorage` に自動保存。
  - **「📋 レポート用テキストをコピー」**：模造紙や画用紙にそのまま貼れる形式でテキスト出力。
  - **「🖨️ まとめシートを印刷・PDF保存」**：A4シートとして印刷可能。

## 📚 夏休み自由研究の進め方モデル（おすすめ構成案）

### 【研究テーマ例】
**「まちと駅のバリアフリー探検隊 〜東急線のエレベーターを歩いて調べたよ〜」**

1. **研究のきっかけ（動機）**
   - ベビーカーや車椅子の人が駅で遠回りしているのを見て、どうして階段の近くにエレベーターがないのか疑問に思った。
2. **予想（仮説）**
   - 新しい駅や病院がある駅のほうがエレベーターが広くて見つけやすいのではないか？
   - 地下の駅と高架の駅でエレベーターの数や乗り継ぎ方が違うのではないか？
3. **調査（フィールドワーク）**
   - ネットの情報をもとに作ったアプリをスマホに入れて、実際に「自由が丘」「大岡山」「中目黒」などを親子で探検！
   - エレベーターの写真を撮ったり、メジャーでドア幅を測ったり、ボタンの押しやすさを確認。
4. **考察・わかったこと**
   - 自由が丘の北口にはエレベーターがなく、正面口に回る必要があること。
   - 大岡山駅は真上に病院があるので、ストレッチャーが入る特大エレベーターがあること。
   - エレベーターの中の鏡は身だしなみ用ではなく、車椅子の人が後ろ向きで降りる時のバックミラーであること。
5. **工夫したこと**
   - 自分だけのオリジナルGPSアプリを作って、困っている人を案内できるようにしたこと！
